# ⚡ NorVex-r

Aplikasi obrolan karakter AI berbasis Perchance yang dikemas dalam *native shell* Android. Ringan, responsif, dan didesain untuk kenyamanan interaksi AI sehari-hari.

---

## ✨ Fitur Utama

- **💬 AI Character Chat:** Berbincang dengan berbagai karakter AI tanpa batas.
- **🎨 UI Rapi & Responsive:** Tampilan dark mode yang nyaman di mata.
- **📁 Ekspor & Impor Cadangan:** Simpan riwayat chat, lore, dan data karakter dengan aman.
- **⚡ Ringan & Cepat:** Dioptimalkan khusus agar tidak membebani RAM dan baterai HP.

---

## 📲 Unduh Aplikasi

Kamu bisa langsung mengunduh file APK versi terbaru di halaman **[Releases](https://github.com/VB-7/NorVex-r/releases)**.

1. Unduh APK rilis terbaru.
2. Install di HP Android-mu.
3. Buka dan langsung gunakan!
